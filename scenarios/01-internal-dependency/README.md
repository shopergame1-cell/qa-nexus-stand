# Сценарій 1: залежність є лише у внутрішньому репозиторії

Приватна бібліотека `qa.scenario:internal-lib` задеплоєна тільки у внутрішній репозиторій стенда.
У Maven Central її немає — і не буде.

**Що робити:** дописати в `consumer/pom.xml` репозиторій стенда так, щоб Maven знайшов артефакт.

```bash
bash setup.sh                        # створити стан
mvn -f /tmp/qa-scenario/01/consumer/pom.xml -Dmaven.repo.local=/tmp/clean dependency:resolve   # упаде
# ...твоя правка...
bash check.sh                        # мусить пройти
```

**Пастка:** додати артефакт у `~/.m2` руками «щоб працювало» — не розвʼязок: у колеги на чистій
машині збірка все одно впаде. Саме це перевіряє сценарій 5.
