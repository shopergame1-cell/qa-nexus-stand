# Сценарій 2: 401 при правильному паролі

Деплой падає з `401 Unauthorized`, хоча логін і пароль точно правильні.

**Що робити:** знайти, чому Maven не бачить пароль. Підказка: він шукає його **за id**.

**Пастка:** спокуса «вписати пароль прямо в pom.xml» — так робити не можна: pom їде в git.
Другий бік задачі — тримати пароль зашифрованим.
