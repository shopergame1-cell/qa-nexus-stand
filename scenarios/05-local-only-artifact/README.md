# Сценарій 5: «у мене працює, у колеги — ні»

Артефакт `qa.scenario:team-lib:1.0.2` лежить лише в локальному кеші `~/.m2` твоєї машини.

**Що робити:** опублікувати його туди, звідки його візьмуть інші, і описати цей шлях у проєкті.

**Пастка:** порада «скинь свій ~/.m2 колезі» — не розвʼязок. Локальний кеш нічого нікому не гарантує:
він зникає при переустановці, не версіонується і не відтворюється в CI.
