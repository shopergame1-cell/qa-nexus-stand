# Сценарій 4: свіжий snapshot не підтягується

Колега задеплоїв новий `1.0.0-SNAPSHOT`, а твоя збірка бере старий.

**Що робити:** розібратись із `updatePolicy` для snapshot-залежностей.

**Пастка:** «видалю ~/.m2 і все запрацює» — так, запрацює один раз. Але питання було не про кеш,
а про політику оновлення; без правки налаштувань проблема повернеться.
