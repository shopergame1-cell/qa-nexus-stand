# Сценарій 6: дві версії однієї бібліотеки

Проєкт прямо залежить від `guava`, і одночасно тягне її транзитивно в іншій версії.

**Що робити:** побачити це через `mvn dependency:tree` і зафіксувати версію явно.

**Пастка:** «працює ж» — працює, доки порядок залежностей у pom не змінився. Maven вибирає
найближчу за деревом версію, і будь-яка перестановка може тихо підмінити бібліотеку.
