# Сценарій 3: mirror перехопив усе

Після налаштування mirror зникли внутрішні залежності.

**Що робити:** зрозуміти, що таке `mirrorOf` і звузити правило так, щоб воно перехоплювало
лише те, для чого його ставили (зазвичай `central` або `external:*`).

**Пастка:** «працює ж» — працює, поки комусь не потрібен внутрішній артефакт. Тоді падає збірка
в усієї команди, а причина неочевидна: у логах видно лише «artifact not found».
